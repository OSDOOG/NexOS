# NexOS Application

This is a NexOS application project generated by `nexos create`.

## Building
To build a Debug build:
```bash
nexos build
```

To build an optimized Release package (`.app`):
```bash
nexos build --release
```

## Running on Hardware
Copy `dist/<app_name>.app` to the `/apps/` folder on your MicroSD card and insert it into your ESP32-C6 running NexOS.
